完整示例：小游戏

仓库里的 examples/game 是一个零依赖、能直接跑的小游戏：登录、客户端商品配置、创建充值、Webhook 验签后加钻石，全都在一个 server.mjs 里。

跑起来

  1. 注册应用在仓库根目录执行，回调地址和示例端口一致：
    npm run app:create -- --name "示例小游戏" --redirect http://localhost:5173/oauth/callback
  2. 填环境变量GS_CLIENT_ID、SPACEPAY_KEY、SPACEPAY_WEBHOOK_SECRET。本地调站点再加 GS_BASE=http://localhost:8080。
  3. 启动node examples/game/server.mjs，打开 http://localhost:5173。
  4. 点登录 → 点充值登录会跳 goutoustdio.top 授权，充值会跳到 SpacePay 收款页；付款后等 Webhook。
iWebhook 要公网 HTTPS 才能收到。本地联调可以先拿内网穿透地址，付款后在 SpacePay 商户后台手动「重投」。

登录：跳转与回调

登录路由只做三件事：生成 PKCE 和 state、存会话、302 到授权页。

if (pathname === "/login") {
  const verifier = crypto.randomBytes(32).toString("base64url");
  const challenge = crypto.createHash("sha256").update(verifier).digest("base64url");
  const state = crypto.randomBytes(16).toString("hex");
  const sid = crypto.randomBytes(24).toString("base64url");
  sessions.set(sid, { verifier, state, player: null });
  setSessionCookie(res, sid);

  const auth = new URL(`${GS_BASE}/oauth/authorize`);
  auth.search = new URLSearchParams({
    response_type: "code", client_id: CLIENT_ID, redirect_uri: REDIRECT_URI,
    scope: "profile email", state, code_challenge: challenge, code_challenge_method: "S256",
  });
  res.writeHead(302, { location: auth.toString() });
  return res.end();
}

回调先比对 state，再用 code + verifier 换令牌，最后读 userinfo：

if (pathname === "/oauth/callback") {
  if (url.searchParams.get("state") !== sess.state) return json(res, 400, { error: "state 不匹配" });

  const tokens = await exchangeCode(url.searchParams.get("code"), sess.verifier);
  const user = await fetchUser(tokens.access_token);

  // sub 是唯一且稳定的玩家主键
  sess.player = { sub: user.sub, username: user.username, displayName: user.display_name || user.username };
  if (!players.has(user.sub)) players.set(user.sub, { ...sess.player, credits: 0 });
  res.writeHead(302, { location: "/" });
  return res.end();
}

充值：商品由客户端传

客户端把整份商品配置（sku、name、price、credits）POST 给游戏服务器，服务器校验格式后下单；没传就用兜底商品（100 钻石）。

const GAME_PRODUCTS = [
  { sku: 'monthly_pass', name: '月卡', price: '5.00', credits: 300 },
  { sku: 'starter_pack', name: '新手礼包', price: '9.90', credits: 600 },
];

const r = await fetch('/api/recharge', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ product: GAME_PRODUCTS[0] }),
});
location.href = (await r.json()).checkout_url;
if (pathname === "/api/recharge") {
  const body = await readBody(req);
  const product = acceptProduct(body.product || body);   // 校验 price / name / credits
  if (!product) return json(res, 400, { error: "商品配置不合法" });

  const reference = `order-${Date.now()}-${crypto.randomBytes(3).toString("hex")}`;
  const order = { reference, sub, sku: product.sku, name: product.name, credits: product.credits,
    amountCents: Math.round(Number(product.price) * 100), status: "pending" };

  const payment = await createPayment(order);   // POST /api/v1/payments
  orders.set(reference, order);
  return json(res, 200, { reference, checkout_url: payment.checkout_url });
}

回调：验签与发货

if (pathname === "/webhooks/spacepay") {
  const raw = await readRaw(req);   // 必须是原始字节
  if (!verifyWebhook(raw, req.headers["x-spacepay-signature"], WEBHOOK_SECRET)) {
    return json(res, 400, { error: "bad signature" });
  }

  const evt = JSON.parse(raw.toString("utf8"));
  if (seenEvents.has(evt.id)) return json(res, 200, { ok: true });  // 幂等
  seenEvents.add(evt.id);

  if (evt.type === "payment.succeeded") {
    const order = orders.get(evt.data.reference);
    if (!order) return json(res, 409, { error: "unknown order" });
    if (evt.data.amount_cents !== order.amountCents) return json(res, 400, { error: "amount mismatch" });
    players.get(order.sub).credits += order.credits;
    order.status = "paid";
  }
  return json(res, 200, { ok: true });
}

付款页：二维码 + 轮询

下单成功后游戏不直接跳收款页，而是回到自己的 /pay/订单号 页面：展示金额与二维码，每 3 秒问一次服务端「到账没」，Webhook 和主动对账都能把订单变成已支付。完整版式与代码见 付款页与二维码。

if (pathname.startsWith("/api/order/")) {
  const order = orders.get(pathname.slice("/api/order/".length));
  if (!order || order.sub !== sess.player.sub) return json(res, 404, { error: "订单不存在" });

  // Webhook 没到时主动对一次账
  if (order.status === "pending") {
    const r = await fetch(`${SPACEPAY_BASE}/api/v1/payments/${order.paymentId}`, {
      headers: { authorization: `Bearer ${SPACEPAY_KEY}` },
    });
    const { payment } = await r.json();
    if (payment?.status === "SUCCEEDED") deliver(order);
  }
  return json(res, 200, { ...order, qr_url: order.qrUrl });
}

引擎里怎么接

场景做法
网页游戏直接 location.href 到授权页；回调用你自己的后端换令牌，别在浏览器里换。
Godot / Unity / 桌面端用系统浏览器打开授权页，回调到 mygame://oauth/callback 这类自定义协议，再交给本地服务端换令牌。
手机游戏同上，用系统浏览器或 ASWebAuthenticationSession / Custom Tabs，不要用内嵌 WebView 收密码。
!自定义协议回调的 redirect_uri 也要在注册应用时登记，并且同样精确匹配。协议回调可能被其它 App 抢注，敏感场景建议加 PKCE + 短时效授权码（本平台已经强制 PKCE）。

上线前检查

  • 密钥只在服务端环境变量；仓库里没有 sp_live_ 或 gs_sk_ 字样。
  • state 每次登录随机、用一次就作废；授权码失败就让玩家重登，不复用。
  • 商品价格与发货数量以订单记录为准，Webhook 只用来触发发货。
  • Webhook 幂等（事件 ID 唯一索引）、5 分钟时间窗、原始请求体验签。
  • 玩家余额变动在事务里写流水，能对账。
  • 退款事件会扣回已发道具，别只处理 payment.succeeded。
