令牌与用户信息

授权码换来的是一对令牌：access token 两小时，refresh token 三十天且每次刷新都换新。玩家资料用 GET /oauth/userinfo 读取，sub 是唯一标识。

有效期

令牌有效期用法
授权码 code10 分钟，一次只在换取令牌时使用
access token2 小时Authorization: Bearer … 调 userinfo
refresh token30 天，每次刷新轮换换取新的 access / refresh，旧的一对立即作废
!刷新令牌是一次性的：刷新成功后必须保存新的 refresh_token。并发刷新会有一个请求失败，这是预期行为——同一玩家请串行刷新。

刷新令牌

POSThttps://goutoustdio.top/oauth/token
curl -X POST https://goutoustdio.top/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d grant_type=refresh_token \
  -d refresh_token=$REFRESH_TOKEN \
  -d client_id=$GS_CLIENT_ID
const r = await fetch('https://goutoustdio.top/oauth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
  body: new URLSearchParams({
    grant_type: 'refresh_token',
    refresh_token: saved.refreshToken,
    client_id: process.env.GS_CLIENT_ID,
  }),
});
if (r.status === 400) return logout(); // invalid_grant：过期或已被用过，让玩家重新登录
const tok = await r.json();
save(tok); // 两个令牌都要更新

读取玩家资料

GEThttps://goutoustdio.top/oauth/userinfo
curl https://goutoustdio.top/oauth/userinfo \
  -H "Authorization: Bearer $ACCESS_TOKEN"
{
  "sub": "10001",
  "username": "alice",
  "display_name": "Alice",
  "bio": "写内核的",
  "profile_url": "/u/alice",
  "admin": false,
  "created_at": 1762800000000,
  "email": "alice@example.com",
  "email_verified": true
}
字段说明
sub账号唯一标识，字符串形式的用户 ID，不会变。用它当玩家主键
username用户名，用于展示。不要把用户名当外键，改名后会对不上
display_name bio昵称与简介，可能为空字符串
profile_url站点个人主页路径，拼上 https://goutoustdio.top 即可
email email_verified仅在授权 scope 含 email 时返回，未验证邮箱的 email_verified 为 false

令牌无效、过期或账号被封禁时返回 401：

{ "error": "invalid_token", "error_description": "access_token 无效或已过期" }

撤销令牌

POSThttps://goutoustdio.top/oauth/revoke

玩家在游戏里「解绑 / 退出」时调用，access token 或 refresh token 都可以传。按 RFC 7009，无论令牌是否存在都返回 200。

curl -X POST https://goutoustdio.top/oauth/revoke \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d token=$REFRESH_TOKEN \
  -d client_id=$GS_CLIENT_ID

账号绑定建议

  • 第一次登录时用 sub 建玩家档，把昵称头像存成缓存；之后每次登录按 sub 查。
  • 支持游客的，先建游客档，登录后把游客档合并到 sub 对应的正式档。
  • 账号被删除或封禁时 userinfo 会返回 401，把它当成「请重新登录」，不要当成网络错误重试。
  • 玩家的游戏内昵称与 GoutouStdio 昵称可以不同；以你游戏内的昵称为准，别每次登录覆盖。
