接入流程

  1. 注册应用，拿到 client_id在服务器上执行一条命令。公共客户端（游戏本体、网页游戏）不生成密钥，只靠 PKCE。
  2. 接入登录把玩家浏览器送到 /oauth/authorize，回调里用 code 换令牌，再取 /oauth/userinfo 得到 sub。
  3. 开通商户，创建充值单在 SpacePay 商户后台申请入驻并创建 API Key，服务端调用 POST /api/v1/payments。
  4. 接收回调，发货配置 Webhook 地址，验签后按 metadata.gs_user_id 给玩家加余额或发道具。

1. 注册应用

在站点服务器上运行（源码在 scripts/create-app.mjs）：

npm run app:create -- \
  --name "我的游戏" \
  --redirect http://localhost:5173/oauth/callback

输出：

应用已创建：我的游戏
  client_id      gs_app_3f7c1a9e5b2d4c60
  类型           公共客户端（无 client_secret，必须用 PKCE）
  redirect_uris  http://localhost:5173/oauth/callback
  scope          profile
  • 服务端渲染的游戏、需要 client_secret 的场景，加 --secret 创建机密客户端。
  • 回调地址必须完全一致；生产环境只接受 https://，本机调试允许 http://localhost。
  • 需要邮箱时加 --scope "profile email"，玩家会额外看到一条授权项。

2. 让玩家登录

生成 PKCE 的 code_verifier / code_challenge，把浏览器跳到授权页（完整参数见 账号登录）：

import crypto from 'node:crypto';

const verifier = crypto.randomBytes(32).toString('base64url');
const challenge = crypto.createHash('sha256').update(verifier).digest('base64url');

const url = new URL('https://goutoustdio.top/oauth/authorize');
url.search = new URLSearchParams({
  response_type: 'code',
  client_id: process.env.GS_CLIENT_ID,
  redirect_uri: 'https://game.example/oauth/callback',
  scope: 'profile',
  state: crypto.randomBytes(16).toString('hex'),
  code_challenge: challenge,
  code_challenge_method: 'S256',
}).toString();

// verifier 和 state 存进玩家会话，回调时要用
res.redirect(url.toString());
https://goutoustdio.top/oauth/authorize
  ?response_type=code
  &client_id=gs_app_3f7c1a9e5b2d4c60
  &redirect_uri=https%3A%2F%2Fgame.example%2Foauth%2Fcallback
  &scope=profile
  &state=4f2a…
  &code_challenge=…
  &code_challenge_method=S256
i玩家已经在 goutoustdio.top 登录过的话，授权页会直接出现「允许 / 取消」；没登录会先去登录页，登录后自动回到授权。

3. 创建充值订单

在 SpacePay 商户后台拿到 sp_live_… 密钥，服务端调用（金额是十进制字符串）：

curl https://pay.goutoustdio.top/api/v1/payments \
  -H "Authorization: Bearer $SPACEPAY_KEY" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": "5.00",
    "currency": "USD",
    "reference": "order-2026-0001",
    "description": "月卡（游戏自定义商品）",
    "success_url": "https://game.example/recharge/done",
    "metadata": { "gs_user_id": "10001", "sku": "monthly_pass" }
  }'
const r = await fetch('https://pay.goutoustdio.top/api/v1/payments', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.SPACEPAY_KEY}`,
    'Content-Type': 'application/json',
    'Idempotency-Key': crypto.randomUUID(),
  },
  body: JSON.stringify({
    // product 是客户端传来的商品配置，服务端校验过格式
    amount: product.price,
    reference: orderId,
    description: product.name,
    metadata: { gs_user_id: player.sub, sku: product.sku },
  }),
});
const { payment } = await r.json();
// 把 payment.checkout_url 交给玩家（跳转或生成二维码）

响应里的 checkout_url 就是收款页。把它给玩家，付款成功后 SpacePay 会 POST 到你的 Webhook。

4. 验签并发货

Webhook 请求头 X-SpacePay-Signature 形如 t=1762800000,v1=…，签名是 HMAC-SHA256(secret, t + "." + 原始请求体)。验过之后再按业务订单号发货，详见 回调与验签。
